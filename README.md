# phro-trend

요즘 뜨는 연구 논문과 한 주의 AI 소식을 **실무자가 바로 쓸 수 있는 한국어 설명자료**로 바꿔 주는 Claude Code 플러그인입니다.

초록이나 뉴스를 다시 풀어 쓰지 않습니다. 지금 흔히 쓰는 방식에서 무엇이 달라졌는지, 어디까지 믿을 만한지, 그 변화를 어떤 개발 구조의 어느 칸에 끼우면 되는지를 짧은 산문과 다이어그램으로 보여 줍니다.

## 스킬

| 스킬 | 하는 일 |
|---|---|
| `phro-trend:ai` | Hugging Face 트렌딩 AI 논문 중 아직 다루지 않은 3편을 골라 HTML 설명자료 한 파일로 만듭니다 |
| `phro-trend:weekly` | 지난 한 주 동안 여러 소스에 나온 AI 소식을 모아 8분 안에 읽히는 HTML 주간 글 한 파일로 만듭니다 |

## 설치

```bash
claude plugin marketplace add ThatsHoon/phro
claude plugin install phro-trend@phro
```

## 사용법: 트렌드 논문 (`ai`)

"트렌드 논문 정리해줘", "hf 트렌딩 페이퍼 설명자료 만들어줘"처럼 요청하면 스킬이 호출됩니다. 직접 부르려면 `/phro-trend:ai`.

결과 파일은 현재 폴더의 `trend-papers/YYYY-MM-DD.html`에 저장됩니다. 본문은 글머리표 없이 이어지는 문단으로 쓰고, 논문마다 기존 대비 비교표 하나와 다이어그램을 둡니다. 논문마다 다음 여덟 칸이 들어갑니다.

| 칸 | 내용 |
|---|---|
| 한 줄로 | 무엇을 무엇으로 바꿔서 무엇이 좋아지나 |
| 기존에는 | 지금 흔히 쓰는 방식의 동작 단계 |
| 무엇이 문제였나 | 그 방식이 깨지는 상황과 비용 |
| 이 논문은 이렇게 바꿨다 | 새 장치의 단계와 기존 대비 비교표 |
| 얼마나 좋아졌나 | 핵심 수치와 잰 조건 |
| 어디에 쓰면 좋나 | 개발 구조 안의 위치를 그린 다이어그램 |
| 예시 | 입력 하나가 기존과 새 방식에서 처리되는 과정 |
| 바로 써보려면 | 코드 공개 여부, 필요 자원, 한계 |

## 사용법: 주간 소식 (`weekly`)

"지난주 AI 소식 정리해줘", "이번 주 AI 트렌드"처럼 요청하거나 `/phro-trend:weekly [YYYY-Www] [관심사...]`로 부릅니다. 주를 주지 않으면 가장 최근에 끝난 주(월요일 0시부터 다음 월요일 0시 전까지)를 다룹니다. 관심사(예: `LoRA 양자화 음성`)를 주면 고를 때 그쪽에 무게를 둡니다. 관심사 밖이라도 그 주의 큰 변화(여러 곳에서 다룬 소식, 큰 곳의 새 모델, 바로 조치할 보안 사고)는 핵심 1건이나 짧은 소식으로 빠뜨리지 않습니다.

결과 파일은 현재 폴더의 `trend-weekly/YYYY-Www.html`에 저장됩니다. 글은 앞에서 멈춰도 그 주를 알 수 있게 층으로 쌓입니다.

| 절 | 내용 |
|---|---|
| 이번 주 한눈에 | 핵심 세 건의 결론 세 문장과, 이번 주 소식을 꽂은 개발 구조 지도 |
| 이번 주 3가지 | 소식마다 무엇이 달라졌나, 어디까지 믿나, 적용 고리, 해보려면 |
| 짧게 보는 소식 | 지도 칸별로 묶은 짧은 소식 |
| 흐름 | 지난 주들과 비교해 이어지는 것, 새로 뜬 것, 잠잠해진 것 |
| 이번 주 해볼 것 하나 | 걸리는 시간과 확인할 기준이 붙은 일 하나 |
| 부록 | 고르지 않은 글 전체와 소스별 수집 현황 |

소스는 Hugging Face Daily Papers, HF 블로그, Ahead of AI, DAIR.AI, Deep (Learning) Focus, Lilian Weng 블로그, Unsloth 릴리스, r/LocalLLaMA와 r/MachineLearning(arctic-shift 보관소를 거침), PyTorchKR, GeekNews, arXiv eess.AS입니다. 각 사이트의 `robots.txt`를 지키고 요청마다 이름을 밝히며, 막힌 곳은 우회하지 않고 수집 현황에 적습니다.

### 쌓기 일정

GeekNews와 arXiv eess.AS는 피드에 하루치 안팎만 남아서, 하루 두 번(09시, 21시) 받아 쌓아야 한 주가 다 모입니다. 처음 호출할 때 스킬이 등록을 제안합니다. 손으로 하려면 다음 명령이 실행기 파일을 쓰고 등록 명령(Windows는 PowerShell, 그 밖은 crontab)을 출력합니다. 출력된 명령을 확인한 뒤 직접 실행하면 됩니다.

```bash
python -I ~/.claude/plugins/cache/phro/phro-trend/<버전>/skills/weekly/scripts/weekly.py schedule
```

실행기는 플러그인을 갱신해도 가장 새 버전을 찾아 돌기 때문에 다시 등록할 필요가 없습니다.

## 기록과 중복 방지

기록은 플러그인 폴더 밖인 `~/.claude/phro-trend/`에 남아서 플러그인을 갱신해도 지워지지 않습니다. 기록은 결과 파일이 검사를 통과한 뒤에만 남습니다.

| 파일 | 내용 |
|---|---|
| `seen.json` | `ai`가 다룬 논문. 다음 호출 때 건너뜁니다 |
| `weekly.json` | `weekly`가 주마다 실은 소식. 다음 주 중복을 막고 흐름 문단의 재료가 됩니다 |
| `pull/` | 쌓아 둔 GeekNews와 arXiv eess.AS 항목(120일 보관) |

처음부터 다시 하려면 해당 파일을 지우면 됩니다.

## 문체

두 스킬은 같은 문체 규칙(`STYLE.md`)을 따르고, 검사 스크립트(`scripts/check.py`)가 결과 파일마다 같은 목록으로 확인합니다. 작성 도구 표기, 이모지, 긴 대시, 상투구와 과장어는 한 번만 나와도 고치게 하고, 번역투나 빈 수식어처럼 하나씩은 자연스러운 말은 몰려 있을 때만 고치게 합니다.

## 요구 사항

- Python 3.9 이상(표준 라이브러리만 사용)
- 인터넷 연결. 공개 API와 피드만 읽으므로 토큰은 필요 없습니다.
- 다이어그램은 mermaid(CDN)로 그려지므로 결과 파일을 열 때도 인터넷이 필요합니다.
